Read the failure, not just the score.

The model learns a mean and sample standard deviation at each pixel from 48 aligned normal images. A separate set of 32 normal images fixes the 95th-percentile image-maximum threshold. Test images never set that threshold.

Move a weak defect from the quieter left half to the noisier right half. Compare raw and standardized residuals. Then remove the defect and shift overall brightness: an alignment-dependent normal model can flag a harmless acquisition change.

The mask threshold is the image-level threshold, not an independently tuned segmentation threshold. Heatmap colors use a fixed scale of twice the selected threshold; score values are not probabilities. IoU compares the current predicted mask with the known injection footprint, not real-world defect labels.

Scope: original 24 × 24 synthetic textures only. No industrial data, neural model, competitive benchmark, calibration guarantee or GPU result is claimed. The original easy 64-image test showed no advantage from standardization. A separate three-run stress study found region-dependent gains and failures, including false alarms on every brightness-shifted normal image. Read the paired study and limitations ↗. This demo uses the original frozen model, not the study's three fitted models.
